石膏晶胞 a 轴

Gypsum unit-cell a axis

来源已核对·开放知识条目

石膏是 CaSO₄·2H₂O 的单斜晶体；本页量晶胞短轴 5.679 Å，b 轴 15.202 Å， c 轴 6.522 Å。这是晶胞参数，不是手标本尺寸。

它是什么

石膏是 CaSO₄·2H₂O，晶体结构由 SO₄ 四面体、Ca 配位多面体和层间水分子组成，属单斜晶系。[1] 本页量的 5.68 Å 是单斜晶胞的一条短轴，是晶胞参数，不是手标本尺寸。[2] 石膏是常见的硫酸盐矿物，含两个结晶水；脱水后会变成半水石膏或硬石膏，晶胞也随之改变。[2] 结构中的水以结晶水形式存在于层间，使石膏硬度很低、易于雕刻。

怎样知道

矿物学手册给出石膏 I2/a 单斜晶胞：a = 5.679 Å、b = 15.202 Å、c = 6.522 Å，β = 118.43°，Z = 4。[1] Mindat 的矿物页列出同一组参数，并注明单斜晶系与石膏超族。[2] 两者数值一致，轴名也一致。单斜晶胞的三个轴互不垂直，β 角 118.43° 描述 a 轴与 c 轴之间的夹角；因此不能像立方晶胞那样只用一个边长。[1] 衍射数据必须同时给出轴长与夹角，才能完整确定晶胞形状。

数值与口径

5.68 Å 等于 5.68×10⁻¹⁰ m、0.568 nm。口径是晶胞的短轴；不同资料可能按不同轴序命名，但 5.679 Å 这条边不变，另一条长边为 15.20 Å。[1][2] 它不是 S—O 键长，也不是 Naica 石膏晶体那种米级尺寸。数值随含水量与温度略变。三个轴长之比约为 1 : 2.68 : 1.15，最短边 5.679 Å 与 c 轴 6.522 Å 相近，而 b 轴 15.202 Å 明显最长。[1] 不同资料对 a、b、c 的指派可能不同，但三条边的长度集合不变。

常见误解

常见误解之一是把 0.568 nm 当成石膏晶体的宏观厚度；天然石膏晶体可长到数米。[2] 另一个误解是把 5.68 Å 的短边与 15.20 Å 的长边对调；两者相差近三倍。[1] 还有人把石膏与硬石膏混同，后者不含结晶水，晶胞不同。常见资料里也常把 5.68 Å 记成 b 轴，原因正是轴序命名不统一；读矿物晶胞数据时，应以三个边长与夹角为准，而不是只看字母。[1][2] 另一个误解是把石膏与熟石膏当成同一种物质，后者是脱水产物。

与其他尺度的关系

0.568 nm 约为 NaCl 晶格常数 0.564 nm 的 1.01 倍，约为石英 a 轴 0.491 nm 的 1.16 倍。[1][2] 它的长边 1.52 nm 已接近 DNA 直径 2 nm。与云母 c 轴 2.0 nm 相比，石膏最长边约为其四分之三。[1][2] 这说明单斜晶胞可以在一个方向上被拉得很长。继续阅读晶格间距、NaCl 晶体与金刚石晶胞，可比较单斜与立方晶系。

适用条件与比较口径

  • 取常温常压下的石膏 I2/a 单斜晶胞，量 5.679 Å 这条短边；b 轴为 15.202 Å， c 轴为 6.522 Å，β 约 118.4°。该值不是 S—O 键长，也不是手标本尺寸。

手册给出 a = 5.679(5) Å，Mindat 列出同一组参数；不同资料可能按不同轴序命名， 但 5.679 Å 这条边不变，故标为近似。
