方解石晶胞 a 轴

Calcite unit-cell a axis

来源已核对·开放知识条目

方解石是 CaCO₃ 的六方/菱面体晶体；本页量晶胞 a 轴 4.9896 Å，c 轴为 17.061 Å。 这是晶胞参数，不是手标本尺寸，也不是 C—O 键长。

它是什么

方解石是 CaCO₃ 的最常见晶型，晶体结构中平面 CO₃²⁻ 基团与 Ca²⁺ 八面体配位交替排列。[1] 本页量的 4.99 Å 是六方/菱面体描述下的晶胞 a 轴，是晶胞参数，不是手标本尺寸。[2] CO₃²⁻ 是平面三角形基团，钙离子处于氧八面体配位，二者沿 c 轴按层堆叠，形成方解石的菱面体解理。[2] 方解石还有很强的双折射，透过厚晶体的光会分成两束。

怎样知道

单晶 X 射线精修给出方解石的 R3c 晶胞：a = 4.9896 Å、c = 17.0610 Å，Z = 6。[1] 大学矿物学教材的数据表给出 a = 4.99 Å、c = 17.04 Å，与前者一致。[2] 这些数值来自衍射，不是图像估读。方解石与菱镁矿、菱铁矿等同属方解石族，结构同型，只是二价阳离子不同，因此族内晶胞参数可以横向比较。[2] 单晶精修与粉末衍射给出的 a、c 值在误差范围内一致。[1]

数值与口径

4.99 Å 等于 4.99×10⁻¹⁰ m、0.499 nm。口径是晶胞 a 轴；c 轴 17.06 Å 约为它的 3.4 倍，不能混用。[1][2] 它也不是 C—O 键长约 1.29 Å，更不是一块方解石晶体的厘米级尺寸。标为近似是因为不同产地与固溶成分会使参数略偏。六方晶胞体积约为 368 Å³；若改用菱面体描述，菱面体棱长约 0.64 nm，与 a 轴不是同一个量。[1] 因此读矿物数据时必须先确认用的是六方轴还是菱面体棱。

常见误解

常见误解之一是把 0.499 nm 当成方解石解理块的边长；肉眼看到的菱面体是宏观晶体。[1] 另一个误解是把 a 轴与 c 轴当成同一方向的两种写法；它们长度差三倍多。[2] 还有人把方解石与文石混同，两者晶型不同，晶胞参数也不同。另有一个误解是把解理菱面的边长当成晶胞 a 轴；解理面是宏观断裂面，边长由手标本决定。[2] 也有人把 c 轴 1.7 nm 当成分子长度，其实它跨越多个分子层。

与其他尺度的关系

0.499 nm 约为 NaCl 晶格常数 0.564 nm 的 0.88 倍，与石英 a 轴 0.491 nm 几乎相同。[1][2] 但方解石的 c 轴 1.706 nm 明显更长，说明晶胞可以高度各向异性。与二氧化碳分子 0.23 nm 相比，a 轴约为其两倍；与 DNA 直径 2 nm 相比则约为四分之一。[2] 继续阅读晶格间距、NaCl 晶体与二氧化碳，可比较碳酸盐与卤化物的结构参数。

适用条件与比较口径

  • 取常温常压下的方解石 R3c 六方晶胞，量 a 轴长度；c 轴为 17.061 Å，二者相差三倍多。 该值不是手标本尺寸、不是 C—O 键长，也不是解理菱面体的宏观边长。

单晶精修给出 a = 4.9896(2) Å，大学矿物学教材给出约 4.99 Å，差异在测量精度内； 固溶成分与温度会使参数略变，故标为近似。
